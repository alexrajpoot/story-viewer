Enter a username (name, @name) or paste a story link.

How this project works

  1. Frontend — plain HTML/CSS/JS in public/, served by Netlify's CDN.
  2. API call — the page calls /api/story?username=… on the same domain.
  3. Backend — a Netlify Function validates the input and asks the provider for stories (or returns sample data in demo mode).
  4. Download — /api/download streams the file back with a "save as" header, only from allowlisted hosts.
Educational project. Not affiliated with Instagram or Meta. Only shows content the configured provider is permitted to return.
